# Release policy

- `0.x.y` while unstable; SemVer after 1.0.
- Previews: `-preview.N` (e.g. `v0.2.0-preview.1`).
- Package version must match release tag.
- Stable packages only from stable tags.
- Manual version bump first; automate only after the process is stable.

Tag examples: `v0.1.0`, `v0.2.0-preview.1`.
